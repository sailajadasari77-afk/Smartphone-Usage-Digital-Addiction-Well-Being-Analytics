1. ABSTRACT

Smartphones have become an important part of our daily lives. People use smartphones for communication, social media, entertainment, education, gaming and other activities. Excessive smartphone usage may be associated with changes in daily habits, sleep and overall well-being.

The project “Smartphone Usage, Digital Addiction & Well-Being Analytics” focuses on analyzing smartphone usage patterns using data analytics and visualization techniques.

In this project, Microsoft Power BI is used to analyze the dataset and create interactive dashboards. The dashboards contain KPI cards, bar charts, pie charts and other visualizations to represent smartphone usage and well-being-related information.

The project helps in identifying different usage patterns and presenting the information in a simple and understandable form. It demonstrates how data visualization can convert raw data into meaningful insights.

---

2. INTRODUCTION

Smartphones are widely used in modern society for many purposes. Although smartphones provide many benefits, excessive or uncontrolled usage can become a concern.

Analyzing smartphone usage data can help us understand how users spend their time on different digital activities.

This project uses data analytics to study factors such as:

- Screen time
- Social media usage
- Gaming
- Notifications
- Sleep duration
- Smartphone-related activities
- Well-being indicators

Power BI is used to transform the raw dataset into interactive dashboards. These dashboards make it easier to compare different categories and identify important patterns.
